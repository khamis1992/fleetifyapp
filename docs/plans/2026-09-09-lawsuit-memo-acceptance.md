## نتائج التحقق

- 96 اختبار قبول للقالب والطلبات والفترات والتجهيز وWord، و4 اختبارات إضافية للمحمل الفعلي المستخدم بالتصدير الفردي والجماعي.
- 111 اختبار قاعدة بيانات للمطالبة والنسخ وبيانات الاتصال وتصحيح الفواتير القديمة والتراجع وحماية نطاق الشركة.
- `npm run type-check`: نجح بعد آخر تعديل للمحمل.
- `npm run build:ci`: نجح بعد آخر تعديل، خلال دقيقة و52 ثانية.
- `npm run finance:ci -- --require-db`: نجح كاملًا؛ يشمل 244 اختبارًا ماليًا، فحص الصلاحيات والأنواع، وسلامة القيود والضوابط والمطابقة الفعلية.
- آخر مطابقة ضمن المسار الكامل: `reports/financial-reconciliation-2026-09-09T01-27-32-539Z.json`، بلا اختلافات. نتيجة الصحة المالية سُجلت بالمعرّف `128e0e2a-8deb-4703-9f4a-b8a69a0e8d7b`.
- ترحيلات قاعدة البيانات المنشورة لها ملفات تراجع مطابقة. تراجع تصحيح الأرصدة إجراء طارئ صريح يحتفظ بالتدقيق، ويرفض استبدال فاتورة تغيرت لاحقًا.
