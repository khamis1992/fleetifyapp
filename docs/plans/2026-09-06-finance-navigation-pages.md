# فصل صفحات المالية وتبسيط التنقل

طلب المستخدم تنفيذ المقترح المعتمد في المحادثة: فصل الوظائف الرئيسية، دمج التنقل المتكرر، إبقاء الأدوات في سياق العمل، والحفاظ على الروابط والصلاحيات والعربية.

## خطة التنفيذ
- [x] تسع مجموعات مختصرة في القائمة، وفتح مجموعة واحدة؛ البحث يصل إلى التقارير والأدوات دون إظهارها كلها في القائمة.
- [x] روابط مستقلة للفواتير والمدفوعات والتحصيل والحسابات والقيود والموازنات والرقابة والإعدادات.
- [x] مكتبة تقارير قابلة للبحث وتقرير مستقل لكل رابط؛ مسار تنقل واضح بدل محدد الأقسام المتكرر.
- [x] توحيد نقطة تسجيل الدفعة اليومية؛ حفظ تسجيل دفعات العقود والاستيراد كأدوات مختلفة الوظيفة.
- [x] تحويل الروابط القديمة مع حفظ المعاملات المهمة ومنع حلقات التحويل.
- [x] اختبارات الروابط والصلاحيات والتفاعلات والعربية، وفحص الأنواع والبناء واختبارات المالية.

البيانات والخدمات المحاسبية المشتركة باقية؛ لا ترحيلات قاعدة بيانات ولا نشر في هذه المهمة.

اكتمل التنفيذ والتحقق المحلي. التفاصيل وحدود الاتصال الحي في `docs/reviews/financial-system-2026-09-06/navigation-pages.md`.
