# Direct access to signed-copy approval

The matching dialog currently embeds a full document library above the relevant action. It also describes evidence from a different query, which can disagree with the current inventory after a copy is removed. For the reported contract, the current signed file is customer-owned, so the contract-only manual approval action correctly does not appear on it.

Replace the default library view with focused cards from the same scoped inventory used by ContractDocuments. Contract copies expose the existing manual identity review. Customer copies expose the existing reviewed attachment flow and open manual review immediately after successful creation. Other uploads/classification remain available in an expandable library.

Use current inventory for status; refresh the separate filing assessment after a successful inventory read. Preserve company/contract ownership validation, original customer files, upload review, server-side identity approval, revision checks and dependent query invalidation. No automatic approval is introduced.

On narrow screens, show the manual review form and a full-size document link before the inline PDF. Keep the observation, reason and attestation prerequisites. Verify absent/present/stale/deleted/conflicting copies, attachment-to-review handoff, failures and readiness refresh using targeted tests and the live browser. Do not approve legal evidence while testing.
