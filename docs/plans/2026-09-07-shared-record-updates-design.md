# تحديث البيانات المشتركة بعد الاستكمال

المشكلة: كانت عمليات تعديل العميل تحفظ سجل قاعدة البيانات، لكن تحديث الذاكرة المؤقتة يغفل مفاتيح مثل `customer-details-new` و`crm-customers-optimized` و`lawsuit-contract-details`. بعض القراءات تستخدم مفاتيح متداخلة من `getQueryKey`، فلا تطابقها بادئة `['customers']` القديمة. كذلك لكل تبويب ذاكرة منفصلة.

التنفيذ: خدمة `recordQuerySynchronization` تعيد قراءة المستهلكين المعنيين بعد نجاح الحفظ، وتتعرف على صيغ المفاتيح الموجودة وتحترم نطاق الشركة ومعرف السجل متى كان موجودًا في المفتاح أو نتيجة القراءة. تُلغى القراءات السابقة لتجنب استبدال نتيجة جديدة برد قديم. لا تُنسخ صفوف العميل فوق استجابات العقود أو القوائم؛ يحتفظ كل قارئ بشكله وروابطه. الصفحات النشطة تُحدّث مباشرة، والصفحات غير النشطة تُعلّم بأنها قديمة لتُقرأ عند فتحها.

تستخدم عمليات تعديل العميل المشتركة الخدمة نفسها، وكذلك تعديل العقد والمركبة ولوحتها وحفظ الوقائع القانونية والإنذارات والأضرار ومستندات العقد. يعرض ملخص العقد الجنسية من سجل العميل المرتبط. لا تُستنتج الجنسية من بلد الإقامة، ولا تُنسخ الحقول القانونية الخاصة بالقضية فوق حقول تشغيلية مختلفة المعنى.

تزامن التبويبات: يرسل `BroadcastChannel` نوع السجل ومعرفه ومعرف الشركة فقط إلى تبويبات التطبيق في المتصفح نفسه ومن نفس الأصل. يعيد كل تبويب القراءة بصلاحياته، ولا يعيد إرسال الإشعار المستلم. يُغلق الاشتراك عند تبديل الشركة أو المستخدم. هذه الآلية لا تُعد إشعارًا لحظيًا بين أجهزة أو متصفحات مختلفة، ولا تشارك بيانات العملاء في رسائل القناة. عدم توفر القناة لا يمنع الحفظ والتحديث داخل الصفحة الحالية.

التحقق: اختبارات باستخدام QueryClient وQueryObserver الفعليين للصفحات القديمة والجديدة، والمزامنة بين عميلين مع محاكاة القناة، وعزل الشركات، والردود المتأخرة، وفشل القراءة. اختبار مسار تعديل العميل مع محاكاة قاعدة البيانات يثبت إرسال الجنسية وحدها مع حقول التدقيق، ثم تحديث قارئي العقد والدعوى. لا يُعدّل عميل فعلي لأغراض الاختبار. لا تُعاد أوامر المطابقة المالية أو يُبدأ رفع دعوى بسبب إشعار تحديث.

المراجع التقنية: [إبطال القراءات في TanStack Query](https://tanstack.com/query/latest/docs/framework/react/guides/query-invalidation)، [قنوات المتصفح](https://developer.mozilla.org/en-US/docs/Web/API/Broadcast_Channel_API).
