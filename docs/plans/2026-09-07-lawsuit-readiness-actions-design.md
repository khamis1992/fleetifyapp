# نواقص الدعوى وإجراءات استكمالها

تظهر جميع النواقص أعلى صفحة تجهيز الدعوى، بدل الاكتفاء بنسبة جاهزية ورسالة عامة. تستخدم القائمة نفس قواعد جاهزية الرفع، مع فصل الموانع عن الملاحظات التي تؤثر في الطلبات المشروطة. لا تتحول الملاحظات إلى موانع جديدة.

كل بند يوضح ما ينقصه ويقدم إجراءً مناسبًا: استكمال الجنسية في نموذج مصغر، فتح ملف العميل أو العقد أو المركبة، أو الانتقال إلى قسم التبليغ أو الحيازة والمحاضر أو الإنذارات أو الحافظة. ينتقل التركيز إلى القسم المقصود. يتبع زر الإجراء التالي أول نقص فعلي.

يستخدم حفظ الجنسية مسار تعديل العميل الحالي مع تحديد الشركة والتحقق والتدقيق، ويرسل حقل الجنسية فقط. تُحدّث قراءة بيانات الدعوى بعد النجاح؛ وتبقى أخطاء الحفظ ظاهرة دون إغلاق النموذج. لا يستنتج النظام الجنسية من الاسم أو بلد الإقامة.

التحقق المنفذ: نجح 23 اختبارًا للنقص المحدد وفصل الملاحظات عن الموانع وحفظ الجنسية وإخفاقه وقواعد بدء الرفع. نجح فحص الأنواع وبناء التطبيق. جرى اختبار الواجهة في المتصفح على سطح المكتب، بما يشمل فتح نموذج الجنسية وتعطيل الحفظ عند فراغها وانتقال التركيز والتمرير إلى حقول الحيازة والإنذارات. يتضمن التنسيق نقاط استجابة للشاشات الصغيرة؛ لم يُنفذ اختبار متصفح بحجم هاتف. اختُبر حفظ الجنسية بمحاكاة عملية التحديث، دون تغيير بيانات عميل فعلي أو بدء رفع دعوى.
