# تنظيم الصفحات والقائمة المالية — ٦ سبتمبر ٢٠٢٦

تم تنفيذ المقترح المعتمد محليًا. لا نشر ولا ترحيل قاعدة بيانات ضمن هذه المهمة.

## النتيجة

أصبحت القائمة تسع مجموعات تضم ٢٥ صفحة رئيسية، بعد أن كانت عشرة مجموعات و٥٧ رابطًا ظاهرًا. يحتوي السجل الموحد الآن ٥٨ وجهة، منها ٣٣ تقريرًا وأداة وتفصيلًا تصل إليها من البحث أو من أدوات الصفحة المناسبة. تفتح مجموعة واحدة في القائمة خارج البحث، ويحدد مسار التنقل الصفحة الحالية والصفحة الأم بدل قائمة الانتقال المكررة.

| المجموعة | الصفحات الرئيسية |
|---|---|
| المركز المالي | نظرة عامة؛ التنبيهات ضمنها |
| الفوترة والتحصيل | الفواتير، المدفوعات، متابعة التحصيل، ودائع العملاء |
| المحاسبة العامة | القيود اليومية، دفتر الأستاذ، دليل الحسابات |
| الخزينة | الحسابات البنكية، التسوية البنكية، الالتزامات الشهرية |
| الموردون والمشتريات | الموردون، أوامر الشراء |
| الأصول والموازنات | الأصول الثابتة، الموازنات، مراكز التكلفة |
| التقارير والتحليل | مكتبة التقارير، التحليل المالي |
| الرقابة والإقفال | الموافقات، سلامة البيانات، الإقفال الشهري، سجل التدقيق |
| الإعدادات المالية | ربط الحسابات، الصلاحيات، إعدادات النظام |

مكتبة التقارير تفتح كل تقرير بعنوان ورابط مستقل. الإيجارات الشهرية وكشف تحصيل العملاء ضمن أدوات التحصيل. الاستيراد وتسجيل دفعات العقود ومراجعة الربط ضمن أدوات المدفوعات. تصنيفات الموردين ضمن صفحة الموردين، وتدقيق الإقفال خطوة مرتبطة بصفحة الإقفال.

## الوظائف والمحافظة على السياق

- مسار القبض اليومي يستخدم نموذج الدفعات المشترك داخل صفحة؛ يدعم العميل دون اشتراط عقد، ويحافظ على سياق العقد والفاتورة والمبلغ في الرابط. حفظ الدفعة يستخدم أمر التسجيل الموجود وحماية تكرار الطلب. تسجيل دفعات العقود الجماعي والاستيراد باقيان بوظائفهما المختلفة.
- دفتر الأستاذ يركز على أرصدة الحسابات، مع البحث وتاريخ الرصيد، وعرض حركات الحساب وتصدير البيانات. فتح الحركات يبدأ حتى تاريخ الرصيد المختار.
- صفحة القيود تستخدم مكوّن إدارة القيود القائم، وتفتح نموذج القيد الجديد، وتعرض الترحيل والعكس والحذف حسب صلاحيات الإجراء.
- تحويل الروابط المدمجة القديمة مركزي ويحفظ معرّفات المستندات والمرشحات والإجراءات والجزء الملحق بالرابط. بقيت حماية الصفحات الإدارية في سجل المسارات وحماية إعدادات المشرف العام.
- أسماء الحسابات العربية لها الأولوية في التقارير. أزيلت نسب تنفيذ الموازنة الثابتة ٦٥٪ و٤٥٪ التي كانت توحي بوجود نتائج فعلية؛ تعرض الصفحة المبالغ المخططة وتوضح عدم توفر نسبة التنفيذ الفعلي في ذلك السجل.

## التحقق

- فحص الأنواع الكامل: ناجح.
- بناء نسخة الإنتاج: ناجح؛ توجد تحذيرات التحزيم المعتادة عن حجم بعض الملفات والوحدات المشتركة.
- فحص جودة الملفات الجديدة والمعاد تنظيمها: دون أخطاء أو تحذيرات.
- المالية المحلية المعزولة: **٢٤٤ اختبارًا ناجحًا**، مع فحوص سلامة الملفات وتغطية الصلاحيات وفحص أنواع المالية. تشمل ٧٠ اختبارًا على قاعدة معزولة، ولا تتضمن كتابة في قاعدة الإنتاج.
- **١١٦ فحص عرض**: ٥٨ وجهة بعرض ١٤٤٠ و٣٩٠ بكسل. جميعها بالعربية واتجاه من اليمين، دون خطأ JavaScript أو تجاوز أفقي أو كتابة بيانات. أضيفت أرصدة وحركات نموذجية إلى بيانات الاختبار؛ ظهر اسم حساب إنجليزي في تقرير المركز المالي، وصُحح وأعيد فحص التقرير بنجاح على القياسين.
- **١٣ سيناريو تفاعل ناجحًا**: ترقيم السجلات والتحديد عبر الصفحات، التصدير الكامل، التنقل والرجوع، فتح الفاتورة من رابط قديم، البحث في القائمة والمكتبة، القيد الجديد، نموذج القبض داخل الصفحة، عرض حركات الحساب وتصدير الرصيد، اختيار حركات بنك محدد، نموذج الجوال، إغلاق قائمته بعد التنقل، وتحويل الروابط القديمة.
- اختبار نسخة الإنتاج الفعلية: بدء صفحة الدخول وإعادة تحميلها بالعربية على متصفح إنجليزي، على سطح المكتب والجوال، بما فيه تفضيل إنجليزي قديم محفوظ.

اختبارات الواجهات المالية استخدمت بيانات محلية وحظرت الكتابة والاتصالات الخارجية. اختبار نسخة الإنتاج تحقق من بدء التطبيق والتعريب؛ لا يدّعي تنفيذ معاملات مالية على البيانات الحية.

## حدود فحص البيانات الحية

نجح فحص السلامة العام للقراءة فقط لشركة واحدة. فحص الرقابة التفصيلي توقف مرتين بسبب `journal_entries: TypeError: fetch failed`. لذلك لا توجد نتيجة مكتملة لفحص الرقابة الحي، ولم تُشغّل مراحل المطابقة واللقطة الحية التالية في تلك المحاولة. هذه النتيجة منفصلة عن نجاح اختبارات التنظيم والمالية المحلية.
